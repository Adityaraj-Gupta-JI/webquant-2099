# Code of Conduct

We are committed to maintaining a respectful, inclusive,
and constructive environment for everyone contributing to
WEBQUANT 2099.

## Expected Behavior

- Be respectful.
- Discuss ideas constructively.
- Accept technical feedback.
- Avoid harassment or discriminatory behavior.
- Focus criticism on the work, not individuals.

## Unacceptable Behavior

Harassment, intimidation, discrimination, personal attacks,
or inappropriate conduct will not be tolerated.

## Enforcement

Project maintainers may remove or reject contributions that
violate this Code of Conduct.
