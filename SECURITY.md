# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.x | Yes |

## Reporting a Vulnerability

Do not publicly disclose security vulnerabilities before
the maintainers have had an opportunity to investigate them.

Report security issues privately to the project maintainers.

## Never Commit Secrets

The following must never be committed:

- API keys
- access tokens
- database credentials
- private keys
- `.env` files
- authentication cookies

Use environment variables instead.

## Financial Data Security

WEBQUANT 2099 is a research/demo system.

Do not submit confidential, private, or personally identifiable
financial information to the application.

## Responsible Disclosure

Please provide:

- Description of the vulnerability
- Reproduction steps
- Potential impact
- Relevant logs or screenshots where safe
